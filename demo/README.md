# Demo Directory

Place the following files here before submission:

- `sahay-demo.mp4` — screen recording showing the full flow:
  1. Install APK and sign in
  2. Pick "IIITDM Kancheepuram", download pack
  3. Explore the map (shelters, risk zones, POIs)
  4. Turn on airplane mode
  5. Tap "Go to safety" — show the flood-aware route
  6. Tap "SOS" — show the SMS composition
  7. Open "Show to a local" phrasebook
  8. Turn off airplane mode
  9. Receive a simulation alert from admin dashboard
  10. Submit a hazard report and see its trust score
